About the event

BUILD IT. RACE IT.

Bring an autonomous robot that follows a black line through curves, crossings and a surprise section. The fastest clean run takes the trophy.

BreakfastFree Wi-FiDrinking waterAir-conditioned pit areaCharging points

Eligibility

  • Open to undergraduate students of any college in India.
  • A valid college ID card is mandatory for on-campus entry.
  • Teams of exactly 3 members; cross-college teams are allowed.
  • All participants must follow the event code of conduct.

Rules

  • Robots must be autonomous; no remote control during the run.
  • Maximum robot size 25 by 25 cm, any power source up to 12 V.
  • Each team gets two timed runs; the best run counts.
  • Judges’ decision on track faults is final.
